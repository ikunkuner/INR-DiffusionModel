# INR-DiffusionModel

Reproduction of the MICCAI 2024 paper:

**Reference-free Axial Super-resolution of 3D Microscopy Images using Implicit Neural Representation with a 2D Diffusion Prior**

This project reproduces the method proposed in the paper using **Implicit Neural Representation (INR)** combined with a **2D diffusion prior** to perform **reference-free axial super-resolution** for anisotropic 3D microscopy images.

Official implementation:  
https://github.com/hvcl/INR-diffusion
